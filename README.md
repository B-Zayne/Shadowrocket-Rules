# Shadowrocket-Rules

An optimized, clean, and reliable Shadowrocket configuration file designed for stable, long-term daily use.

---

## 1. Import via Direct URL (Recommended)

### Subscription Links

* **CDN Accelerated (Fastest & Most Reliable):**
  ```text
  [https://fastly.jsdelivr.net/gh/B-Zayne/Shadowrocket-Rules/refs/heads/main/Shadowrocket_rules.conf
  ```
* **GitHub Raw (Backup):**
  ```text
  https://raw.githubusercontent.com/B-Zayne/Shadowrocket-Rules/refs/heads/main/Shadowrocket_rules.conf
  ```

### Steps:
1. Copy one of the URLs above.
2. Open **Shadowrocket**, then go to the **Config** tab at the bottom.
3. Tap the **`+`** icon in the top-right corner.
4. Paste the URL into the input field and tap **Download**.
5. Tap the newly downloaded configuration in your list and select **Use Config** to activate it.

---

## 2. Import via Text Code Copy

Use this method if you prefer to manually update or paste the raw configuration directly into Shadowrocket.

### Steps:
1. In this repository, click on `rules.conf`.
2. Click the **Copy raw file** button (the copy icon on the top right of the file preview).
3. Open **Shadowrocket** and navigate to the **Config** tab.
4. Long-press any existing local configuration file (or tap the `i` / more icon next to it), then select **Edit Plain Text**.
5. Select all existing text, delete it, paste the copied rules, and tap **Save**.

---

## 3. Import via Local File Download

### Steps:
1. In this repository, click on `rules.conf`.
2. Tap the **Download raw file** button to save `rules.conf` directly to your device's Files app.
3. Open **Shadowrocket**, navigate to the **Config** tab.
4. Tap **Import from Files** (or use the iOS share sheet from the Files app to share the `.conf` file into Shadowrocket).
5. Once imported into the local list, tap the file and select **Use Config**.
